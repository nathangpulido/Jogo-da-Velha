🕹️ Jogo da Velha - HTML, CSS e JavaScript

Um jogo da velha clássico de dois jogadores, desenvolvido com HTML, CSS e JavaScript puro, diretamente no navegador. Simples, responsivo e divertido!


🚀 Funcionalidades

🎮 Dois jogadores (X e O) se alternam

🧠 Verificação automática de vitória ou empate

🎨 Interface simples e intuitiva


🛠️ Tecnologias Utilizadas

HTML5

CSS3

JavaScript

📦 Instalação

Clone o repositório
git clone https://github.com/nathangpulido/Jogo-da-Velha/tree/master

# Acesse a pasta do projeto
cd Jogo-da-Velha

# Abra o index.html no navegador

Ou acesse online aqui: https://nathangpulido.github.io/Jogo-da-Velha/
